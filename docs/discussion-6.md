# Відкрита дискусія: символи, кодування та рядки

## Як комп'ютер зберігає літеру, якщо вміє зберігати тільки числа?

Кожному символу Unicode відповідає числовий код. Кодування, наприклад UTF-8,
перетворює ці числа на байти, які можна записати у файл або передати мережею.
Програма читає байти й декодує їх назад у символи.

## Чому `'A'` і `"A"` — це різні речі?

У Java `'A'` — літерал типу `char`, тобто одне 16-бітове UTF-16 code unit.
`"A"` — об'єкт `String`, який містить послідовність таких одиниць; послідовність
може мати нуль, один або багато символів. Додаткові Unicode-символи можуть
займати два `char`, тому `char` не завжди дорівнює повному Unicode code point.

## Чим порожній рядок відрізняється від відсутнього?

`""` — наявний рядок із довжиною 0. `null` означає, що посилання не вказує
на об'єкт `String`. Перед викликом `isEmpty()` слід переконатися, що рядок не `null`.

## Звідки беруться «кракозябри» замість тексту?

Коли байти декодують не тим кодуванням, яким їх записали. Наприклад, UTF-8,
прочитаний як Windows-1251, може перетворитися на неправильні символи. Треба
використовувати узгоджене кодування; для нових текстових файлів зазвичай обирають UTF-8.

## Скільки літер у смайлику 👨‍👩‍👧?

Видимо це один emoji-графемний кластер. Усередині — п'ять Unicode code point:
чоловік, ZWJ, жінка, ZWJ і дівчинка. У Java UTF-16 рядку `length()` поверне 8,
бо три emoji займають по два `char`, а два ZWJ — по одному.

## Чому слово «Привіт» у файлі важить більше, ніж «Hello»?

У UTF-8 латинські ASCII-літери в `Hello` займають по одному байту — разом 5.
Кожна літера в `Привіт` займає по два байти — разом 12. Кількість видимих літер
і кількість байтів не зобов'язані збігатися.
