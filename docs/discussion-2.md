# Відкрита дискусія: цілі числа та їхнє представлення

## Чому комп'ютер рахує двійками, а не десятками?

Електронні схеми надійно розрізняють два стани — наприклад, низьку та високу напругу.
Їх зручно позначити як 0 і 1. Двійкова система напряму відповідає цим двом станам, тому
схеми для неї простіші й менш чутливі до похибок, ніж схема з десятьма рівнями.

## Що таке біт і чому байт має вісім бітів?

Біт — найменша двійкова одиниця інформації: 0 або 1. Вісім бітів утворюють байт і можуть
представити 256 різних комбінацій. Історично розмір байта не завжди був однаковим, але
вісім бітів стали загальноприйнятим стандартом у сучасних комп'ютерах.

## Як записати від'ємне число нулями й одиницями?

Найпоширеніший спосіб — додатковий код (two's complement). Для 8-бітного числа спершу
записують модуль, інвертують усі біти й додають 1. Наприклад, `5` — це `00000101`;
`-5` у 8-бітному додатковому коді — `11111011`. Старший біт допомагає визначити знак.

## Чому виникає переповнення і як його уникнути?

Тип має обмежений діапазон. Наприклад, знаковий 32-бітний `int` зберігає числа від
`-2 147 483 648` до `2 147 483 647`. Якщо результат виходить за ці межі, виникає
переповнення; у Java звичайні цілочисельні операції можуть перейти до протилежного краю
діапазону. Допомагають перевірка меж до операції, ширший тип (`long`), `Math.addExact`
для контрольованого додавання або `BigInteger` для дуже великих значень.

## Чому максимум золота в старих іграх — 2 147 483 647?

Це `2^31 - 1` — найбільше значення знакового 32-бітного `int`. Якщо лічильник золота
зберігався в такому типі, програма не могла представити більше значення без зміни
представлення або перевірки переповнення.

## Чому комп'ютер вважає, що `7 / 2 = 3`?

У Java, коли обидва операнди — цілі числа, ділення теж дає ціле число. Дробова частина
відкидається: `7 / 2` дорівнює `3`, а `7.0 / 2` — `3.5`. Для від'ємних чисел Java
відкидає дробову частину в напрямку до нуля, а не завжди вниз.
