# Практична 8. Дискусія

## 1. Як знайти найбільше число в масиві?

Взяти перший елемент за поточний максимум і порівняти з ним решту.
Починати з нуля неправильно: у масиві можуть бути лише від'ємні числа.
Час — `O(n)`, додаткова пам'ять — `O(1)`.

## 2. Чому задачі на масив часто починаються з одного проходу?

Щоб знайти максимум, суму або кількість потрібних елементів, достатньо
переглянути кожен елемент один раз і зберігати поточний результат.
Без додаткових відомостей про масив зазвичай не можна пропустити елемент:
саме він може змінити відповідь. Один прохід — добра початкова оцінка,
але не універсальний розв'язок для кожної задачі.

## 3. Що робити з порожнім масивом?

Це залежить від змісту результату. Сума, кількість пар і довжина серії
для порожнього масиву дорівнюють нулю. Максимуму в ньому немає:
можна повернути `OptionalInt.empty()` або відхилити аргумент винятком.
Важливо визначити поведінку, а не звертатися до елемента з індексом 0.
Обидва розв'язки цієї практичної повертають 0 для порожніх даних.

## 4. Як за один прохід знайти дні купівлі й продажу акцій?

Під час проходу зберігати найнижчу ціну серед попередніх днів та її індекс.
Для кожного нового дня обчислювати прибуток від продажу за поточною ціною.
Якщо він кращий за попередній, зберегти прибуток і обидва індекси.
Після цього оновити мінімум. Так купівля завжди передує продажу.

Для `[7, 1, 5, 3, 6, 4]` найкраще купити другого дня за 1 і продати
п'ятого за 6: прибуток 5. Якщо ціни лише падають або днів менше двох,
вигідної угоди немає. Час — `O(n)`, пам'ять — `O(1)`.

## 5. Як швидко відповідати на запити суми діапазону?

Один раз побудувати префіксні суми: `prefix[0] = 0`,
`prefix[index + 1] = prefix[index] + numbers[index]`.
Для індексів від `left` до `right` включно відповідь —
`prefix[right + 1] - prefix[left]`.

Якщо рахувати елементи від 1, сума з 10-го по 1000-й —
`prefix[1000] - prefix[9]`. Підготовка займає `O(n)` часу й пам'яті,
кожен запит — `O(1)`. Для великих сум варто використати `long`.
Після зміни елементів префіксні суми потрібно оновити.

## 6. Чи корисно вчити готові прийоми?

Корисно, якщо розуміти, чому вони працюють і які мають обмеження.
Наприклад, два вказівники в задачі 2824 працюють після сортування.
Якщо сума крайніх елементів менша за `target`, для поточного лівого
підходять усі елементи до правого включно. Якщо ні — найбільший правий
елемент не підходить до жодного з решти лівих, і його можна пропустити.

Запам'ятати лише код недостатньо: спочатку треба перевірити умови задачі,
а вже потім вибирати прийом. Для списку довжиною до 50 також підходить
простий перебір усіх пар за `O(n²)`.
