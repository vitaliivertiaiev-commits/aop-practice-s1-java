# DevOps: термінал і файлова система

## Термінал, shell і операційна система

Графічний інтерфейс і термінал — два способи попросити ту саму операційну систему виконати
дію. Наприклад, створення теки через файловий менеджер і команда `mkdir` приводять до
однакового результату. Термінал особливо корисний для дій, які потрібно повторити,
записати або передати іншій людині.

Між користувачем і операційною системою працює **shell** — програма, яка читає команди та
запускає інші програми. Поширені варіанти — Bash і Zsh. `$SHELL` показує shell, призначений
системою, а `ps -p $$` — процес shell, який працює саме зараз; ці значення можуть відрізнятися.

## Файлова система і шляхи

Файлова система зберігає дані у файлах і впорядковує їх у теках. `pwd` показує поточну
теку, `ls` — її вміст, `cd` — змінює поточну теку, `mkdir` — створює теку.

- **Абсолютний шлях** починається з `/` і не залежить від поточної теки, наприклад
  `/Users/ivan/dev/project`.
- **Відносний шлях** рахується від поточної теки, наприклад `src/main` або `../other`.
- `.` означає поточну теку, `..` — батьківську, `~` — домашню.
- Прапорець `-p` у `mkdir -p` створює відразу всі відсутні батьківські теки.

Помилка «файл не знайдено» часто виникає, коли відносний шлях виконують не з тієї теки.

## Вправи з терміналом

Виконуйте команди по черзі й читайте їхній вивід. Приклад нижче створює навчальні теки у
домашній директорії:

### 1. З'ясувати, який shell працює

```bash
echo "$SHELL"
ps -p $$
which zsh
which bash
```

`which` показує шлях до програми, якщо вона встановлена; якщо shell не встановлений,
команда може нічого не вивести.

### 2. Перевірити поточну теку та її вміст

```bash
pwd
ls
ls -l
ls -la
```

`-l` додає докладний список із правами, власником, розміром і датою; `-a` показує також
приховані файли, імена яких починаються з крапки.

### 3. Створити дерево тек і перейти між ними

```bash
mkdir -p ~/dev/terminal-lab/src/main
cd ~/dev/terminal-lab
pwd
cd src/main
pwd
cd ../..
pwd
cd ~
pwd
```

Тут `cd src/main` переходить відносно поточної теки, `cd ../..` піднімається на два рівні,
а `cd ~` переходить абсолютним шляхом до домашньої теки.

### 4. Порівняти відносний і абсолютний шляхи

```bash
cd ~/dev/terminal-lab
ls src/main
cd src
ls src/main
ls main
ls ~/dev/terminal-lab/src/main
```

Після `cd src` команда `ls src/main` шукає `src/src/main` і завершується помилкою.
`ls main` спрацьовує, бо шлях рахується від теки `src`; повний шлях теж спрацьовує
незалежно від поточного місця.

### 5. Порівняти файловий менеджер і термінал

Створіть теку `gui-example` у файловому менеджері, потім перевірте її в терміналі:

```bash
ls -la ~/dev/terminal-lab
```

Створення мишею та `mkdir` створюють звичайну теку в тій самій файловій системі. Bash і Zsh
також підтримують розгортання фігурних дужок:

```bash
mkdir -p ~/dev/terminal-lab/lecture-{01..16}
ls ~/dev/terminal-lab
```

Одна команда створює 16 тек `lecture-01` … `lecture-16`.

### 6. Перевірити систему та використання диска

```bash
uname -a
uname -s
df -h ~
du -sh ~/dev/terminal-lab
```

`uname` показує інформацію про операційну систему, `df` — вільне місце на файловій системі,
а `du` — обсяг, який займає конкретна тека.

## Що заскрінити для практичної

Зробіть справжні скриншоти термінала з командами та їхнім виводом: визначення shell,
`pwd`/`ls -la`, створене дерево тек і переходи, перевірка шляхів, 16 тек `lecture-*`,
а також `uname`, `df` і `du`. Вивід залежить від системи, тому у звіті залишайте саме
результати свого середовища.
