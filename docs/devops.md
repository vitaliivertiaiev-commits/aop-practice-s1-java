# DevOps: термінал і файлова система

## Що таке термінал

Термінал — текстовий спосіб керувати операційною системою. Користувач вводить команду,
оболонка (наприклад, Bash) розбирає її, запускає програму та показує результат.
Команди можна поєднувати в послідовності й автоматизувати у скриптах.

## Файли та каталоги

Файлова система зберігає дані у файлах і впорядковує їх у каталогах. Кожен файл має шлях:

- абсолютний шлях починається від кореня файлової системи, наприклад `/home/student/project`;
- відносний шлях рахується від поточного каталогу, наприклад `src/main/java`.

Команда `pwd` показує поточний каталог. `ls` переглядає його вміст, а `cd` змінює поточний
каталог. `.` означає поточний каталог, `..` — батьківський.

## Корисні команди

| Команда | Призначення |
| --- | --- |
| `pwd` | Показати поточний каталог |
| `ls -la` | Показати всі файли, зокрема приховані |
| `cd src/main/java` | Перейти до каталогу |
| `mkdir -p docs` | Створити каталог разом із відсутніми батьківськими каталогами |
| `touch notes.txt` | Створити порожній файл або оновити час його зміни |
| `cat notes.txt` | Вивести вміст файлу |
| `cp source.txt copy.txt` | Скопіювати файл |
| `mv old.txt new.txt` | Перейменувати або перемістити файл |
| `find . -type f` | Знайти файли в поточному каталозі та вкладених каталогах |
| `rm file.txt` | Видалити файл |

Перед `rm` потрібно перевірити шлях: видалення може бути незворотним. Не запускайте
команди видалення з незнайомими параметрами або шляхами.

## Робочий приклад для цього проєкту

З кореня репозиторію:

```bash
pwd
ls -la
find src -type f
mvn test
```

Maven бере налаштування з `pom.xml`, компілює файли з `src/main/java` і запускає тести
з `src/test/java`. Результати збірки він записує до `target/`; ця папка не додається в Git.
