# Самостійна 12. Автентифікація

У тимчасовому репозиторії змінив адресу `origin` з HTTPS на SSH через
`git remote set-url`. Основний remote залишив без змін.

У тому ж репозиторії перевірив, що значення `.env` залишається в попередньому
коміті після видалення файлу: `git show HEAD~1:.env`. Використав навчальне
значення, не справжній токен.
