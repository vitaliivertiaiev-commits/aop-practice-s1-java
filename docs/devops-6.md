# Практична 6: DevOps — процеси

Ці вправи запускаються безпосередньо у Shell, окремими командами; сценарії `.sh`
у репозиторій не додаються. Перед вправами створіть робочу теку:

```bash
mkdir -p ~/dev/files-lab
cd ~/dev/files-lab
```

## 1. Програма та запущений процес

Перед початком перевірте `jobs -l`; не завершуйте старі або чужі завдання.

```bash
which sleep
ls -l "$(which sleep)"
sleep 60 &
PID60_1=$!
sleep 60 &
PID60_2=$!
ps aux | grep "sleep 60" | grep -v grep
jobs -l
```

Файл `sleep` на диску — програма. Кожен запуск створює окремий процес із власним PID.

## 2. Прочитайте вивід `ps`

```bash
ps aux | head -1
ps aux | head -10
ps -p $$
```

Перший рядок `ps aux` — заголовки. `ps -p $$` показує поточний Shell-процес;
`$$` — його PID.

## 3. Зупиніть процес звичайним сигналом і сигналом `-9`

Спочатку завершіть один процес `sleep 60` через job number, який показує `jobs -l`.
Якщо щойно створені процеси мають номери `%1` і `%2`, завершіть `%1`, а потім приберіть
другий за збереженим PID:

```bash
jobs -l
kill %1
jobs -l
kill "$PID60_2"
jobs
```

Для другого прикладу збережіть PID саме щойно запущеного процесу, перевірте його й
лише потім надішліть `-9`:

```bash
sleep 300 &
PID=$!
ps -p "$PID" -o pid,stat,cmd
kill -9 "$PID"
jobs
```

`kill` спершу просить процес завершитися; `kill -9` припиняє його без можливості
прибрати за собою. Не застосовуйте `-9` до PID, якого не створили для цієї вправи.

## 4. Передній план і фон

Запустіть `sleep 30` на передньому плані й натисніть Ctrl+C. Потім виконайте:

```bash
sleep 30 &
PID30=$!
jobs
fg
```

Коли процес повернеться на передній план, натисніть Ctrl+Z. Після цього:

```bash
jobs
bg
jobs
kill "$PID30"
```

`Ctrl+Z` призупиняє процес; `bg` продовжує його у фоні, `fg` повертає на передній план.

## 5. Запустіть HTTP-сервер

У першому Shell запустіть сервер на передньому плані:

```bash
cd ~/dev/files-lab
python3 -m http.server 8000
```

Відкрийте другий Shell і перевірте процес:

```bash
ps aux | grep "http.server 8000" | grep -v grep
```

Поверніться до першого Shell і зупиніть сервер Ctrl+C. Тепер запустіть його у фоні:

```bash
python3 -m http.server 8000 &
HTTP_PID=$!
jobs
kill "$HTTP_PID"
```

## 6. Знайдіть і завершіть процеси за назвою

Запускайте лише ці два процеси й перед `pkill` перевірте, що вивід показує саме їх:

```bash
sleep 500 &
PID500_1=$!
sleep 500 &
PID500_2=$!
pgrep -af '[s]leep 500'
pkill -f '[s]leep 500'
pgrep -af '[s]leep 500'
```

`pgrep` знаходить PID, а `pkill` надсилає сигнал знайденим процесам. Не запускайте
`pkill`, якщо у виводі є процеси `sleep`, які не належать цій вправі. Дужки в
`[s]leep` не дають пошуку збігтися з власною командою `pgrep`/`pkill`.

## 7. Перевірте навантаження

```bash
top
```

У `top` натисніть `P`, щоб сортувати за CPU, `M` — за пам'яттю, `q` — вийти.
