# Практична 8. DevOps: оточення

## 1. Локальна й експортована змінні

```bash
MY_LOCAL=локальна
export MY_EXPORTED=експортована
echo "$MY_LOCAL / $MY_EXPORTED"
bash -c 'echo "у дочірньому: [$MY_LOCAL] [$MY_EXPORTED]"'
```

Дочірній процес отримує лише експортовану змінну.

## 2. PATH

```bash
echo "$PATH"
printf '%s\n' "$PATH" | tr ':' '\n'
which java
which git
```

`PATH` містить каталоги пошуку програм, розділені двокрапками.
`which` показує знайдену програму та її шлях.

## 3–4. Власна команда й постійне налаштування

Для вправ створюється окремий домашній каталог. У ньому `~/bin/hello`
друкує привітання, але спочатку не знаходиться за коротким ім'ям.

```bash
export PATH="$PATH:$HOME/bin"
hello
which hello
```

Після додавання каталогу команда працює. Новий shell без цієї зміни
знову не знаходить її. Рядок `export PATH="$PATH:$HOME/bin"` у `~/.zshrc`
робить налаштування постійним для інтерактивного zsh цього оточення.
`source ~/.zshrc` застосовує його одразу.

## 5. Aliases

```bash
alias gs='git status -s'
alias gl='git log --oneline --graph --decorate -20'
gs
gl
alias
```

Аліаси скорочують команди. Для збереження між сеансами їх також
додають до `~/.zshrc`.

## 6. Налаштування редактора

```bash
export EDITOR=nano
git config --global core.editor "$EDITOR"
printenv EDITOR
printenv HOME
env | sort | head -20
```

Ці команди виконуються в окремому навчальному оточенні:
глобальний Git-конфіг належить його тимчасовому `HOME`.
У ньому немає ключів і токенів основного оточення.

## 7. Oh My Zsh

Oh My Zsh завантажується в zsh з темою `robbyrussell` і плагіном `git`.
У запрошенні видно поточну гілку навчального репозиторію.

```bash
type gs
type ls
```

`type` відрізняє alias від функції або зовнішньої програми.
Налаштування вправи не змінюють основний профіль термінала.
